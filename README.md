# Texta — веб-мессенджер

## Запуск

```bash
npm install
npm start
```

Сервер поднимется на `http://localhost:3000` — открывайте этот адрес в Chrome, Яндекс.Браузере
и т.д. Все данные (пользователи и сообщения) хранятся на сервере в файле `database.json`,
поэтому синхронизируются между любыми браузерами/устройствами, обращающимися к одному серверу.

## Как пользоваться

1. **Регистрация** — вводите `@username` и отображаемое имя. Сервер выдаёт секретный код
   вида `TC-123456` — он нужен для входа с других устройств/браузеров.
2. **Вход** — `@username` + секретный код.
3. **Поиск** (иконка лупы) — ищет пользователей на сервере по `@username` или имени.
4. **Избранное** — личные заметки, всегда закреплено сверху списка чатов.
5. **Настройки профиля** (иконка шестерёнки) — смена отображаемого имени, просмотр
   username/кода, выход из аккаунта.

## Структура

- `server.js` — Express-сервер и REST API (`/api/register`, `/api/login`,
  `/api/profile/update`, `/api/search`, `/api/messages`).
- `index.html` — разметка всех экранов (авторизация, список чатов, чат, настройки).
- `style.css` — тёмная тема в духе Material 3 / Telegram Dark, 100dvh-адаптив под мобильные.
- `app.js` — клиентская логика: сессия в `localStorage`, запросы к API, рендер экранов.
- `database.json` — создаётся автоматически при первом запуске сервера.
